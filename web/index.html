Official UCI APS dataset

60,000 labelled training rows, 170 anonymised sensor features and a severe class imbalance. The model predicts APS-related failure, not all vehicle faults.

Model status and validation

Checking whether a trained model is installed on this backend.

No measured metrics loaded.

Upload Scania sensor CSV for prediction

Backend inference

CSV must contain all 170 feature headers from the official dataset and up to 500 data rows. Do not include the class target column. Predictions work only after the model has been trained locally. The displayed 0–1 score is a class-weighted model score, not a calibrated real-world failure probability.

Scope and safety: The classifier is specific to the Scania heavy-truck APS dataset. A high-risk output recommends professional inspection; it is not a diagnosis. A low score does not guarantee safety. It is not a passenger-car engine or tyre model.

Training and evaluation protocol

Run python train_model.py after downloading the official CSV to data/raw/. The script creates a stratified hold-out validation split and reports precision, recall, F1, PR-AUC, ROC-AUC, confusion matrix and the published cost-sensitive score. See training guide.
