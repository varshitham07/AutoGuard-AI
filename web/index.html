Official UCI APS dataset

60,000 labelled training rows, 170 anonymised sensor features and a severe class imbalance. The model predicts APS-related failure, not all vehicle faults.

Open official dataset ↗
◈

Model status and independent test metrics

Checking whether a trained model is installed on this backend.

No measured metrics loaded.

Upload Scania sensor CSV for prediction

Backend inference

CSV must contain all 170 feature headers from the official dataset and up to 500 data rows. Do not include the class target column. Predictions work only after the model has been trained locally. The displayed score is a class-weighted model score, not a calibrated real-world failure probability.

Scope and safety: The classifier is specific to the Scania heavy-truck APS dataset. A high-risk output recommends professional inspection; it is not a diagnosis. A low score does not guarantee safety. It is not a passenger-car engine or tyre model.

Training and evaluation protocol

Run python train_model.py after downloading the official CSV to data/raw/. The script creates a stratified 70/15/15 training, calibration and independent test split and selects the alert threshold on calibration data and reports precision, recall, F1, PR-AUC, ROC-AUC, confusion matrix and challenge cost on the untouched test partition. See training guide.

How to interpret the result

01
Evidence firstEvery flag is linked to the submitted pressure or temperature value.
02
Vehicle-specific thresholdsUse OEM/tyre-maker specifications for tyre size, axle, load and operating condition.
03
Single-reading limitationThis screen evaluates one manually entered reading. It does not calculate leak rate or pressure-loss trends.
Pressure flags compare against optional limits you enter from the vehicle or tyre maker. Temperature flags use demonstration thresholds (70°C elevated, 90°C high), not universal safety limits. A normal screen does not guarantee tyre safety; sudden structural failures may occur without an earlier pressure warning.

Before you contact a mechanic

Helpful checklist
  • Share your vehicle make, model and year.
  • Explain the warning light or symptom clearly.
  • Mention when the issue started and whether it repeats.
  • Ask for an estimate covering parts and labour.
  • Confirm warranty, timing and service details.
If you notice brake failure, smoke, fuel leakage, overheating or a serious warning light, stop in a safe place and seek professional help. Do not continue driving just to reach a workshop.
